A free home inventory spreadsheet for Singapore

Version 1.0 · Last updated 20 October 2026 · 3 minute read

An Excel workbook that lists what you own, which room it is in and which box it is packed in. When you need the specific tool, the spare keys or the gifts you're looking for, you type the name and find the row. No sign-up and no email address.

Free download

Blank template Example copy

Small Excel files (.xlsx). The example copy holds made-up data for a fictional family, so you can see how it fits together.

What is inside

  • Inventory. One row per item: name, category, room, box, exact spot, quantity, value, purchase date, brand or serial number, photo file name and notes.
  • Boxes. One row per box: its label, room, where it is kept and a short note on what is inside. The sheet counts how many items you have listed for each box.
  • Summary. Total number of items and their value, then totals by room and by category. It updates by itself.

Dropdown lists for category and room stop typing mistakes. Total value is quantity times value each. If you leave the quantity empty, it counts as 1.

Start in three steps

  1. Walk through one room at a time. Type one row for each item, or one row for a group of the same thing and set the quantity.
  2. Write a label on every box, such as Box 12. Type the same label in the Box or container column, and add the box to the Boxes sheet.
  3. Open the Summary to see the totals.

Type money as a plain number such as 1200 and dates such as 15 Mar 2027. Values are your own estimates, not valuations.

If you may need to claim

Keep the receipt or a clear photo of anything valuable, and note the photo’s file name in the Photo file name column. Insurers differ in what proof they ask for, so ask yours before you need it. This workbook is a record of what you own, not proof for a claim.

What it does not do

It does not store photos, send reminders, work out what things are worth or share between family members. It handles Singapore dollars only. The FamilyHub SG app has a home inventory that holds photos and is shared with your family.

Check it before you rely on it

We compared every Summary total with a separate calculation, using the example copy. That check was done in LibreOffice. The file is built for Microsoft Excel and uses only plain formulas. We have not been able to check Google Sheets or Apple Numbers, so compare the Summary with your own sums if you use either.

Keep it safe

This list shows what you own and where it is. Save it somewhere private and back it up. Do not type passwords, full account or card numbers, or NRIC numbers.

Questions

Is it really free?

Yes. There is nothing to sign up for and no email address to hand over. Use it, copy it and share it.

Does anything I type leave my computer?

No. It is an ordinary Excel file with no macros and no internet connection. We never see what you type. It stays wherever you save it.

How many items can it hold?

The Inventory sheet has room for 299 rows and the Boxes sheet for 99. To add more, copy the last row and paste it below. Group identical things into one row and set the quantity.

Can I put photos in it?

Not inside the file. Take photos with your phone, give each one a clear name, and type that name in the Photo file name column. The FamilyHub SG app can hold the photos themselves.

Can I import it into the FamilyHub SG app?

Not yet. It may come in future, and if you would like it, email support@familyhubsg.com.
